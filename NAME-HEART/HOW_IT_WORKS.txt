HOW IT WORKS - A Heart for You
ASLNS / @ft.aslns / 2026

The repeated name itself forms the heart; there is no separate central label.
A parametric heart curve is sampled into points. Each horizontal row intersects
that curve to find its left and right edges, including the two top lobes.
Whole copies of the typed name fill each row. A subtle pulse changes the curve,
and pink highlights travel through the rows.

Desktop: click the name field, type up to 24 characters, then press Enter.
Mobile: a live browser canvas rebuilds the heart whenever the name input changes.
Share artwork preserves the name in the link. No names are stored in the repository.

Space pause; R restart; S screenshot; Esc quit (outside the desktop input field).
The browser provides play/pause, restart and fullscreen controls.
